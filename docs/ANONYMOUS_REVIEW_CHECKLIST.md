# Anonymous Review Checklist

- No datasets are committed.
- No checkpoints or generated experiment outputs are committed.
- No server usernames, passwords, SSH commands, personal paths, or access tokens
  are committed.
- Public entrypoints use paper-aligned names.
- Original implementation files are retained only for compatibility.
- Dataset root is controlled by --dataset_path.
- The default TaFD setting is K=2 through --domains 2.
